<h1>Linear Regression From Scratch</h1>

<p>
    A simple implementation of <strong>Linear Regression from scratch using NumPy</strong>,
    without using Scikit-learn's LinearRegression model.
</p>

<hr>

<h2>Overview</h2>

<p>
    This project demonstrates how Linear Regression works internally using
    mathematical operations and NumPy.
</p>

<ul>
    <li>Gradient Descent implementation</li>
    <li>Ordinary Least Squares (Normal Equation)</li>
    <li>Model training and prediction</li>
    <li>Weight and bias calculation</li>
    <li>NumPy-based matrix operations</li>
</ul>

<hr>

<h2>Methods Implemented</h2>

<h3>1. Gradient Descent</h3>

<p>
    Gradient Descent iteratively updates the weights and bias to minimize
    prediction error.
</p>

<h3>2. Ordinary Least Squares</h3>

<p>
    The Normal Equation calculates the optimal parameters directly.
</p>
